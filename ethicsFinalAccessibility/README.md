# Web Accessibility 

#### Abstract:
Web accessibility is an important aspect of development to ensure that the web is an inclusive environment that aligns with the vision of universality by its creators.
This entails creating intentional design choices that allow websites and digital media to be compatible with assistive technology and to accomodate the needs of the visually, auditory, physical, and cognitive impairments. All websites are required by law to comply with accessibility guidelines to prevent any form of discrimination, though enforcement of these regulations is very limited, partially due to a lack of public awareness of the issue.
Our project consisted of two parts. Firstly, we utilized an online accessibility auditor to identify the areas of non-compliance in the Stuyvesant Website, and we corrected the HTML code for the website in order to rectify these shortcomings. Secondly, we coded our version of an auditor, which was based on regex expressions, which we then used to audit our own test website for specific accessibility requirements.
